


# Dự án: Quản lí web game
> đây là một dự án phát triển bởi một tân sinh viên ngành **IT** của *Học viện Công nghệ bưu chính Viễn thông*

| Thư mục | nội dung |
| --- | --- |
|data | chứa các giao dịch được kiểm kê và ghi lại |
|logs | chứa các file log và báo cáo |
|media | chứa toàn bộ hình ảnh và logo game|

```PowerShell
Get-ChildItem -Recurse -Force
```
- [x] đọc báo cáo và ghi lại
- [ ] chạy thử web game

>**Lưu ý:** Không upload file .env lên repository.
